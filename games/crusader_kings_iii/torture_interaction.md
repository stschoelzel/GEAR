# Torture (prisoner interaction)

Game: [Crusader Kings III](game.md).

## 0. Torture (prisoner interaction)

### Description

| | |
|---|---|
| Location | character interaction menu for prisoners |
| Available | whenever the player's character holds prisoners |

Torture is one of several interactions with prisoners. Others include blinding and castration.

## 1. Torturing a prisoner

### Description

Choosing the interaction Torture for a prisoner.

### Observation

The player chooses Torture for a prisoner. The effects on the torturer depend on faith and traits: +100 piety with the tenet Exaltation of Pain; -10 stress with the trait Sadistic; +10 stress with Trusting; +100 stress with Compassionate. The victim gets the opinion modifier Tortured Me (-75 for 50 years) and the modifier Recently Tortured (-0.75 health for 5 years). A prisoner can reveal a secret it knows to avoid the torture.

### Interpretation

Torture is a rule with numbers: it costs or pays in piety and stress and is weighed like any other action. Faith and character traits decide whether it is a cost or a gain.
