# How To Win Friends And Influence Enemies

Game: [World of Warcraft](game.md).

## 0. How To Win Friends And Influence Enemies

### Description

| | |
|---|---|
| Part | Wrath of the Lich King, death knight starting zone |
| Quest | [How To Win Friends And Influence Enemies, ID 12720](https://www.wowhead.com/quest=12720) |
| Location | Plaguelands: The Scarlet Enclave, Crypt of Remembrance; New Avalon |
| Quest giver | Prince Keleseth |
| Class | death knight only |

The quest is part of the linear chain every new death knight goes through. The death knight is to find out about the Crimson Dawn from the Scarlet Crusade.

## 1. Keleseth's Persuaders

### Description

Objective of the quest.

### Observation

Prince Keleseth tells the player to take Keleseth's Persuaders from a jeweled box and equip them. The player strikes Scarlet Crusade soldiers in New Avalon with the Persuaders until one of them gives information about the Crimson Dawn.

### Interpretation

Within the linear death knight chain the torture is part of becoming the class.
