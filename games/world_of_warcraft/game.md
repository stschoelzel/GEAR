# World of Warcraft

## Description

Online role-playing game by Blizzard Entertainment, released in 2004 and updated continuously since. Content changes with patches; the version at the time of observation is recorded in each event.

## Reference source

[Wowhead](https://www.wowhead.com). Blizzard offers no official database of quests and NPCs; Wowhead is the one the community relies on. IDs in descriptions are taken from there.
