# The skill Torture

Game: [The Burning Wheel](game.md).

## 1. Torture as a skill

### Description

The rule, as listed in the index and supplements.

### Observation

The rules list Torture as a skill of its own, apart from Interrogation and Intimidation. In The Magic Burner, the skill Torture is a requirement for blood magic based on torture.

### Interpretation

Torture is an option for player characters, built into the rules like any other skill.

Open: In the official forum, a player says the skill description states that the victim confesses what the torturer wants to hear, so that the precise truth is no valid intent for the skill ([Burning Wheel forums, Mundane Skills](https://forums.burningwheel.com/t/mundane-skills-how-impactful-should-they-be-and-how-to-avoid-one-trick-ponies/23449)).
