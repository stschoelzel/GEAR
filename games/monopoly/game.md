# Monopoly

## Description

Board game for two to eight players, published by Parker Brothers from 1935 and owned by Hasbro today. It goes back to The Landlord's Game, patented by Elizabeth (Lizzie) Magie in 1904. Many editions and licensed variants exist; rules differ between them, and house rules are widespread. The edition is recorded in each event.

## Reference source

The rules published by Hasbro for the edition played, and [BoardGameGeek](https://boardgamegeek.com/boardgame/1406/monopoly) as the database the hobby relies on.
